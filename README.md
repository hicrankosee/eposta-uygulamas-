# eposta-uygulaması-
C# ile geliştirilmiş Ad,Soyad,Eposta ekleme güncelleme ve silme (CUD)işlemlerini içeren masaüstü uygulaması
Yaklaşık 3.5,4 saatte bitirdim okulda öğrendiğimiz ekle sil butonuna ilave olarak güncelle butonunu koda ve tasarıma ekledim.
Daha sonra verilerin kalıcı olarak saklanması için projeyi SQL Server ile veri tabanına bağladım ve gerekli tabloları oluşturdum.
Geliştirme sürecinin bazı aşamalarında modern yapay zeka araçlarından yardım aldım.
